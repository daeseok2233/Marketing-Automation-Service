1차 목표: 블로그 04/05/06 각각 하루 10개 = 총 30개 포스팅
최종 목표: 블로그 01~06 전부 하루 포스팅 자동화

**중복 방지 조건:**
- 각 블로그는 자기 블로그의 최근 7일 이력만 체크
- blog_04 생성 → blog_04의 7일간 제목/지역+업종 검사
- blog_05 생성 → blog_05의 7일간만 검사 (blog_04와 독립)
- 블로그 01~06 전부 동일 규칙 적용
- 다른 블로그끼리는 같은 주제 OK

**Why:** 같은 블로그에 중복 글은 SEO 불리 + 독자 이탈. 블로그 간은 독립 운영
**How to apply:** schedule_state.json에 blog ID 추가 → 블로그별 이력 필터링

**발행 전략:**
- 한번에 10개 몰아서 X → 일정 시간 간격으로 1개씩 생성+발행
- 시간마다 바뀌는 실시간 트렌드 반영 가능
- 사람처럼 보이는 발행 패턴 → 네이버 저품질 회피

**아직 미반영 사항:**
- local_issue / local_event 전용 프롬프트 (현재는 local_trend 프롬프트로 통일)
- run.py에 blog04/05/06 별도 명령 추가
- 블로그별 중복 관리 로직
- 스케줄러 (1시간 간격 자동 실행)
